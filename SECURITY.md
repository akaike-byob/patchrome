# Security policy

patchrome drives a real Chrome with your logged-in profile, so a bug can expose cookies, sessions or
local files. Please report vulnerabilities privately.

## Reporting

Open a private report at
[github.com/akaike-byob/patchrome/security/advisories/new](https://github.com/akaike-byob/patchrome/security/advisories/new).
Do not open a public issue.

Include the patchrome version (`npm ls -g patchrome`), your OS, and steps to reproduce. Expect a first
reply within 5 working days.

## Supported versions

Only the latest release gets security fixes.
